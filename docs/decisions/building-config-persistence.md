# 건물 설정 저장과 복귀 조건

## Decisions

- 건물 설정(지상·지하 층수, 대수, 인테리어 분위기, 안내 언어)은 브라우저에 저장해 다음에 열 때도 이어간다.
- 로비의 설정 버튼은 호출을 기다리는 중(어떤 차도 응답하거나 문이 열려 있지 않은 상태)에만 보인다.
- 설정을 바꾸고 다시 "시작"을 누르면, 이전에 서 있던 층과 무관하게 새 건물의 지상 1층부터 시작한다.

## Why

매번 설정부터 다시 하면 "혼자서도 끝없이 반복되는 최소한의 놀이"라는 `PRODUCT.md`의 핵심 루프가 열 때마다 끊긴다. 엘리베이터가 응답하는 중에 건물을 바꾸면 진행 중이던 동작이 애매해지므로, 설정 화면 복귀는 대기 중일 때만 허용한다.

## Reconsider when

- 설정을 브라우저에 남기는 방식이 실제 사용 기기(태블릿 크롬)의 저장 공간 제한이나 시크릿 모드에서 잘 동작하지 않는다고 확인될 때. 저장이 안 되면 매번 설정 화면부터 시작하는 것으로 자연히 대체된다.
