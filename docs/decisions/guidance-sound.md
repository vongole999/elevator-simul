# 안내 소리

## Decisions

- 안내 음성은 브라우저 내장 음성합성(Web Speech API)으로 낸다.
- 도착 종소리 같은 비음성 효과음은 Web Audio API로 합성한다.
- 녹음 음원 파일은 저장소에 두지 않는다.

## Boundaries

- 소리 품질이 아이의 "따라 말하기"를 끌어내지 못한다고 관찰되면 이 결정을 다시 연다.
- 안내 언어를 늘릴 때도 같은 방식으로 처리한다. 언어별 음원을 새로 마련하지 않는다.

## Why

음원을 쓰면 실제 아파트 안내 방송에 가장 가깝지만, 음원 확보가 구현 바깥의 작업이라 한 번에 만들고 검증하는 흐름이 끊긴다. 브라우저 내장 합성은 코드만으로 완결되고, 언어를 늘릴 때 추가 비용이 거의 없다.

## Reconsider when

- 아이가 안내 멘트를 따라 말하지 않거나, 합성 억양이 어색해 실감이 깨진다고 관찰될 때.
- 실제 사용 기기(태블릿 크롬)에 쓸 만한 ko-KR 음성이 없다고 확인될 때.

## Still-rejected alternatives

- 녹음 음원 파일 — 음원 확보·라이선스·언어 확장 비용이 구현 바깥에서 발생한다; 합성 음성이 실감에 못 미친다고 관찰되면 다시 검토한다.

## Evidence worth preserving

- 이 프로젝트의 개발 브라우저(Windows Chromium)에서 `speechSynthesis.getVoices()` 결과에 `Microsoft Heami / ko-KR / local`이 있고, `AudioContext`를 쓸 수 있음을 2026-08-27에 확인했다. 아이가 실제로 쓰는 태블릿 크롬에서는 아직 확인하지 않았다.
