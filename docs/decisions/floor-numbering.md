# 층 표기

## Decisions

- 지하층은 층 표시기와 층 버튼에 `B1`, `B2`… 로 표시한다.
- 지상 층수는 2~200층, 지하 층수는 0~20층 범위에서 아이가 +/- 버튼으로 정한다.

## Boundaries

- 이 표기는 층 번호가 화면에 보이는 모든 곳(층 표시기, 호출·층 버튼, 안내 문구)에 똑같이 적용한다.
- 안내 음성에서 지하층을 어떻게 읽을지(예: "지하 1층입니다")는 이 결정의 범위가 아니다. 음성 문구는 구현 시 자연스럽게 정한다.

## Why

`B1`은 실제 국내 엘리베이터 버튼에서 가장 흔히 보는 표기라 아이에게 낯설지 않다. "지하1, 지하2…"는 읽기는 쉽지만 버튼 라벨이 길어져 층 버튼 그리드가 빽빽해진다. "-1, -2…"는 간결하지만 음수 개념이 익숙하지 않은 어린 아이에게는 헷갈릴 수 있다.

층수 범위는 처음엔 층당 이동 시간(0.6초/층, [[guidance-sound]]와 별개로 `single-elevator-round-trip` 스펙에서 정함) 기준으로 최대 이동(지상 30+지하 5=35층)이 20초 안팎이 되도록 잡았다. `PRODUCT.md`의 "50층까지 30초" 기준 안에 든 값이었다.

이후 더 높은 건물도 만들어보고 싶다는 요청으로 최댓값을 지상 200층·지하 20층까지 넓혔다. 이 최댓값까지 실제로 채워서 타면 이동 시간은 그 기준을 크게 넘는다(현재 층당 이동 시간 0.9초 기준 최대 이동 약 3분). 최댓값은 "설정으로 만들 수 있는 상한"이고 아이가 매번 그만큼 큰 건물을 고른다는 뜻은 아니라고 보고, 우선은 범위만 넓혀두고 실제로 큰 값을 고르는 빈도와 그때의 체감은 놀아보고 재검토한다. 최소 지상 2층은 엘리베이터가 존재할 최소 조건이다.

## Reconsider when

- 아이가 `B1` 표기를 헷갈려 하거나 읽지 못한다고 관찰될 때.
- 층수 범위가 실제로 너무 좁거나 넓어 재미가 없다고 관찰될 때.
- 아이가 큰 층수를 실제로 골라서, 이동 시간이 길어져 지루해한다고 관찰될 때. 그때는 최댓값을 다시 좁히거나 층당 이동 시간을 값에 따라 다르게 주는 것을 검토한다.

## Still-rejected alternatives

- `지하1, 지하2…` — 버튼 라벨이 길어져 그리드가 빽빽해진다; `B1` 표기가 아이에게 어렵다고 관찰되면 다시 검토한다.
- `-1, -2…` — 음수 개념이 익숙하지 않은 아이에게 헷갈릴 수 있다; 같은 조건이면 다시 검토한다.
