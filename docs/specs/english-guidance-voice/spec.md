# 영어 안내 음성

## 사용자 결과

아이가 설정 화면에서 영어를 고르고 건물을 시작하면, 호출부터 하차까지 한 바퀴에서 나오는 모든 음성 안내("문이 열립니다", "올라갑니다", "3층입니다" 같은 것들)가 영어로 들린다. 도착 종소리는 언어와 무관하게 지금과 똑같이 난다. 한국어를 고르면 지금처럼 전부 한국어로 들린다.

`building-setup`(설정 화면)이 이미 만들어 둔 언어 선택 값이 지금은 저장만 되고 실제로는 쓰이지 않는데, 이 값을 실제 음성 안내에 연결해서 `PRODUCT.md`의 "안내 언어(한국어/영어)"와 `building-setup` 스펙이 미뤄뒀던 "영어 안내 음성의 실제 구현"을 완성하는 단위다. 이 스펙이 끝나면 `building-setup` 스펙의 수용 기준 8번("영어를 고르고 시작해도 안내 소리는 한국어로 난다")은 더 이상 맞지 않게 되고, 이 스펙이 그 조항을 대체한다.

## 승인된 범위

- 설정 화면에서 고른 언어(한국어/영어) 값을 엘리베이터 화면까지 실제로 전달해서, 음성 안내에 반영한다.
- 지금 한국어로 나가는 모든 음성 안내 문구를 영어로도 갖춘다: 문 열림, 문 닫힘, 상행/하행, 도착 층 안내, 층 버튼을 눌렀을 때의 안내.
- 층 버튼을 눌렀을 때의 안내는 층 이름만 짧게 말한다(예: 한국어는 "4층", 영어는 "Floor 4"). 기존의 "4층 눌렀습니다"처럼 동작을 함께 말하지 않는다. 언어와 무관한 변경이라 한국어에도 함께 적용한다.
- 영어를 고르면 위 문구 전부가 영어 음성으로, 한국어를 고르면 지금과 동일하게 한국어 음성으로 난다.
- 지하층이 있는 건물에서도 영어 안내가 자연스럽게 난다.

## 관찰 가능한 수용 기준

1. 설정 화면에서 영어를 고르고 "시작"을 누른 뒤 로비에서 호출 버튼을 누르면, 곧이어 나는 음성 안내가 영어로 들린다.
2. 엘리베이터가 도착하면 도착 종소리가 나고(언어 무관, 기존과 동일), 이어서 영어로 문이 열린다는 안내가 들린다.
3. 안쪽 화면에서 층 버튼을 누르면 "Floor 4"처럼 층 이름만 말하는 영어 음성이 들리고, 문이 닫힌 뒤 이동 방향(상행/하행)도 영어로 들린다. 한국어 건물에서는 같은 자리에서 "4층"처럼 층 이름만 들린다.
4. 목적 층에 도착하면 도착 층 안내와 문 열림 안내가 모두 영어로 들린다.
5. 지하층을 호출·선택했을 때도 1～4와 같게 영어로 자연스럽게 들린다.
6. 한국어를 고르고 시작하면 지금과 완전히 같게 모든 안내가 한국어로 들린다.
7. 마우스 클릭과 터치 어느 쪽으로 눌러도 1～6이 같게 일어난다.

## 정해진 제약과 이유

- 영어 안내도 브라우저 내장 음성합성(Web Speech API)으로 낸다. 음원 파일을 새로 마련하지 않는다. `docs/decisions/guidance-sound.md`가 "안내 언어를 늘릴 때도 같은 방식으로 처리한다"고 이미 정해 둔 근거를 그대로 따른다.
- 도착 종소리는 Web Audio API로 합성한 소리 그대로 두고 언어별로 다르게 만들지 않는다. 종소리는 말이 아니라 신호라 언어와 무관하다.
- 화면에 보이는 글자(호출·층 버튼 라벨, 층 표시기, 로비·설정 화면의 문구 등)는 이번 범위에 넣지 않는다. `PRODUCT.md`와 `building-setup` 스펙이 말하는 "안내 언어"는 일관되게 음성 안내를 가리키며, 화면 문구 번역은 이 결정들이 다루지 않은 별개의 작업이다.

## 가정

아래는 뒤집는 비용이 싸고, 틀렸을 때 바로 눈에 띄는 값이다. 다르게 하고 싶으면 언제든 바꾼다.

- 층 버튼 눌렀을 때를 뺀 나머지 문구의 정확한 워딩은 구현 시 정한다. 기존 한국어 문구와 뜻이 같고 자연스러운 영어면 된다(예: "문이 열립니다" → "Doors opening", "올라갑니다" → "Going up").
- 지하층은 "지하 2층입니다"에 대응해 "Basement 2"처럼, 지상층("Floor 5")과 같은 문장 구조로 자연스럽게 읽는다. 화면 표기(`B2`)를 글자 그대로 읽지 않는다.
- 언어 값은 `building-setup`의 기존 흐름과 같게, "시작"을 누른 시점의 값이 그 건물이 유지되는 동안 적용된다. 로비에서 설정으로 돌아가 언어만 바꾸고 다시 "시작"을 누르지 않으면, 이미 시작된 건물의 안내는 바뀌지 않는다.
- 영어 음성 선택은 한국어와 같은 방식(브라우저가 제공하는 영어 음성 중 하나를 고르는 것)을 따르고, 특정 지역 억양(en-US/en-GB 등)을 못박지 않는다.

## 범위 밖

- 화면에 보이는 글자(버튼 라벨, 층 표시기, 로비·설정 화면 안내문 등)의 번역.
- 한국어·영어 외의 다른 언어.
- 분위기(모던·클래식·우주선)별로 안내 소리를 다르게 내는 것. `building-setup` 스펙에서 이미 범위 밖으로 둔 것이다.
- `PRODUCT.md`에서 이미 범위 밖으로 둔 것들(점수·미션 등 게임 요소, 관리자 모드·건물 경영·엘리베이터 설계).

## 미룬 것

- 영어 문구의 최종 워딩과 억양. 아이가 실제로 듣고 어색하면 그때 다듬는다.

## 남은 위험

- 아이가 실제로 쓰는 태블릿 크롬에 쓸 만한 영어 음성이 없을 수 있다. 개발 브라우저에서는 확인이 필요하고, 태블릿에서는 이번에도 확인하지 않는다.
- 숫자·지하 표기를 브라우저가 영어로 읽는 방식은 브라우저·OS마다 조금씩 달라, 문구를 자연스러운 문장으로 풀어 써도 실제 발음이 기기마다 다르게 들릴 수 있다.
- 영어 안내의 속도·난이도가 초등학생이 듣고 따라 말하기에 적절한지는 아이가 들어봐야 안다.
